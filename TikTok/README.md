# TikTok Interaction Lab

تجربة React/Vite صغيرة كتختبر شريط الإشعارات والردود فوق فيديوهات TikTok عامة. الواجهة RTL وبستايل داكن، والرسائل الموجودة فيها محلية وتجريبية فقط.

## التشغيل

من داخل هذا المجلد:

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## ملاحظات تقنية

الفيديوهات كتتحمّل باستعمال TikTok embed الرسمي عبر `https://www.tiktok.com/embed.js`. التطبيق ما كينزّلش الفيديوهات وما كيعيدش استضافتها، وما كيحتاج حتى API key. عرض الفيديو ممكن يتأثر بالمنطقة، المتصفح، cookies، أو سياسات TikTok؛ لذلك التطبيق كيبقى فيه نص تحميل واضح.

الـBackend موجود في `server.js` ويقدم API حقيقية بـ Express. البيانات كتتخزن بشكل دائم في `data/tiktok.json`، وتشمل users، الفيديوهات، التعليقات، وlikes. المجلد `data/` مستثنى من GitHub حتى ما يترفعوش بيانات المستخدمين، وخص الاستضافة تكون عندها disk دائم أو يتم تبديل التخزين بقاعدة بيانات مستضافة قبل production واسع.

زر `+ طيّح رسالة دابا` كينشئ إشعاراً محلياً، بينما التعليقات وlikes كيمشيو للـBackend وكيتم تخزينهم. الربط الحقيقي بحسابات TikTok أو المراسلة داخل TikTok ماشي جزء من هاد النسخة وكيحتاج API وصلاحيات منفصلة.
